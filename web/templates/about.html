About this project

Project Overview

This is a behavioral-signal analysis prototype built for GDG TechSprint (3rd Prize). It measures how a speaker's blink rate, gaze, head movement and voice change relative to their own baseline. It produces a signal-consistency report, not a lie/truth verdict.

The first 20 seconds of a recording are treated as the speaker's baseline. Every later 5-second window is compared against it, and each signal is expressed as a z-score against the baseline's own spread.

Technology Stack

Computer Vision

  • OpenCV
  • MediaPipe Face Mesh
  • Eye aspect ratio (blinks)

Audio Processing

  • librosa (pyin pitch)
  • Jitter / shimmer / pauses
  • Whisper ASR (optional)

Fusion & reasoning

  • Per-speaker baseline z-scores
  • NumPy
  • Google Gemini (optional)

Web Framework

  • Flask
  • JavaScript
  • HTML/CSS

Key Features

👁️ Face signals

Blink rate and head-movement variance from MediaPipe Face Mesh landmarks

🔍 Gaze

Fraction of frames where the iris sits away from the centre of the eye

🎵 Audio Pattern Analysis

Pitch mean and variability, jitter, shimmer, speech rate and pause ratio

🧠 AI-Powered Reasoning

Optional: Gemini turns the numbers into a plain-English summary that always carries the ethics caveat

📊 Comprehensive Reporting

Per-signal table and chart, downloadable as JSON

🔐 Privacy Focused

Uploads are deleted right after analysis (and after 30 minutes if never analysed); reports stay in your browser tab only

Important Disclaimer

There is no scientifically validated physiological or behavioral "lie signature". This prototype measures change from a baseline, which can come from stress, cognitive load, culture, neurodivergence, anxiety or recording conditions.

Do not use it for hiring, policing, legal proceedings or any other high-stakes decision. Only analyse recordings made with the speaker's consent.
